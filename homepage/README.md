# EKSPAN website redesign concept

Independent static prototype. Open index.html locally, or serve this folder with a static web server. No build step or dependencies required.

Includes the homepage, bearing catalogue and nine bearing detail pages, services, projects, news, brochure downloads and contact email preparation.

This is not the live EKSPAN website. The contact page prepares an email only. Original project assets and published PDF brochures are included as copies. Product specifications and publication content require EKSPAN approval.
